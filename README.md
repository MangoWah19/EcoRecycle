# EcoRecycle

EcoRecycle is an Android-based recycling participation application developed to encourage university students to participate in recycling and sustainability activities more conveniently.

The application provides an integrated platform where users can record recycling activities, participate in sustainability missions, track recycling transactions, and access sustainability learning content.

## Main Features

### Recycling Deposit

* Submit recycling deposits
* Scan QR codes for recycling collection
* Track recycling deposit status

### Transaction Management

* View previous recycling transactions
* Track submitted recycling activities and their status

### Sustainability Missions

* Browse available sustainability missions
* Join sustainability activities
* Submit proof of mission completion
* Track mission participation status

### Sustainability Learning

* Browse sustainability-related educational content
* Learn about recycling and sustainable practices

### Offline Accessibility

* Access cached application data without an internet connection
* Preserve selected user and application data locally
* Synchronize data when connectivity becomes available

## Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* Retrofit
* REST API
* JWT Authentication
* Room Database (SQLite)
* WorkManager
* Git
* GitHub

## Application Architecture

EcoRecycle follows a mobile application architecture where the Android application communicates with a backend system through REST APIs using Retrofit.

Room Database is used for local data storage and offline accessibility, while WorkManager supports background tasks and data synchronization.


## Project Objective

The main objective of EcoRecycle is to reduce barriers to recycling participation by providing a convenient and integrated digital platform.

By combining recycling tracking, sustainability missions, educational content, and offline accessibility, the application aims to encourage users to participate in sustainability activities and remain involved over time.

## Project Information

EcoRecycle was developed as part of a university Final Year Project focusing on recycling participation and sustainability.

This repository contains the Android mobile application responsible for the participation module of the EcoRecycle ecosystem.

## Getting Started

### Requirements

* Android Studio
* Android SDK
* Kotlin
* Android device or emulator

### Installation

1. Clone the repository.

```bash
git clone <your-repository-url>
```

2. Open the project in Android Studio.

3. Allow Gradle to synchronize the required dependencies.

4. Configure the backend API endpoint if required.

5. Run the application using an Android emulator or physical Android device.
